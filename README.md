# MCDRplugin

TPW 的 MCDReforged 插件 / 资源仓库。

## 插件（独立仓库）

| 插件 | 版本 | 源码 / 文档 | Release |
|---|---|---|---|
| 简单放置破坏榜 (SimplePlacedMinedScoreboard) | v1.5.0 | [simpleplacedminedscoreboard](https://github.com/20051111/simpleplacedminedscoreboard) | [v1.5.0](https://github.com/20051111/simpleplacedminedscoreboard/releases/tag/v1.5.0) |
| 仓库审计日志 (WarehouseAuditLog) | v1.0.4 | [mcdr-warehouse-audit](https://github.com/20051111/mcdr-warehouse-audit) | [v1.0.1](https://github.com/20051111/mcdr-warehouse-audit/releases/tag/v1.0.4) |

- **简单放置破坏榜**：侧边栏实时显示八个统计榜单，数据包逐 tick 累加，无需 RCON；命令 `!!spms`
- **仓库审计日志**：监控仓库容器取出行为，SQLite 记录 + CSV 导出，不卡服；命令 `!!wh`

## 目录

| 目录 | 内容 |
|---|---|
| [`plugins/`](plugins/) | 插件分发文件（与各仓库 Release 一致） |
| [`材质包/`](材质包/) | 服务器材质包相关文件 |
